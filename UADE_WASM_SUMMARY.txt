⚡ CORE MECHANICS
═══════════════════════════════════════════════════════════════════════════════

IPC Model:
  Native:  fork() → socketpair() → blocking socket I/O
  WASM:    ring buffers → pull-triggered synchronous calls

Synchronization:
  1. JavaScript calls render()
  2. libuade needs audio, calls read()
  3. read() finds response empty
  4. Calls uadecore_handle_one_message() (synchronous)
  5. 68k emulation runs until audio ready
  6. Response written, read() returns
  7. Audio returned to JavaScript

State Machine:
  Phase 1: CONFIG + Hardware init (once per module)
  Phase 2: SCORE + Module load (per song)
  Phase 3: Config messages (filter, frequency, etc)
  Phase 4: m68k_run_1() (continuous emulation)
